# 再平衡天平 · 3D demo

用 Vite + Vanilla JS + Three.js 做的 3D 天平：左盘放高波动资产（R4 及以上），右盘放低波动资产（R1–R3）。两边的占比都等于目标时天平是平的；哪边超配，哪边就往下沉，偏得越多沉得越深。

- 托盘里每一层是一个标的，颜色和主应用一致；层高按「当前市值 / 该侧目标市值」算，细圈标出目标高度
- 右侧改持有股数，天平实时跟着变；点「按目标再平衡」，持仓在约 2 秒内过渡到目标，天平再慢慢摆回水平
- 「模拟一周行情」按风险等级随机波动价格，用来看天平怎么偏
- 鼠标：拖动托盘上下压/抬横梁，松手后缓慢回正；拖动空白处旋转视角，滚轮缩放；悬停在色层上看该标的的占比和偏离

价格取自 `../app/data/prices-weekly.json` 的最新一周（人民币、港币资产按当周汇率折成美元）；示例持仓与主应用一样，是一年前按目标买入 18,000 美元后自然漂移的结果。持仓保存在浏览器的 `heng.balance` 里。

```bash
npm install
npm run dev     # http://localhost:5179
```
